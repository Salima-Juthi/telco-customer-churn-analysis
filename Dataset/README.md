# Dataset Information

This project uses the IBM Telco Customer Churn dataset.

Before redistributing the raw data, verify the original source, license, and applicable usage terms.

The SQL analysis table contains 7,032 rows, while the Power BI report contains 7,043 rows. The difference has not yet been reconciled.

If the raw dataset is not included in this repository, obtain it from the verified original source and import it into MySQL before running the SQL scripts.
