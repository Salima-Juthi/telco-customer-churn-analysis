# Power BI Report

This folder contains the Power BI report for the Telco Customer Churn Analysis project.

The report includes three pages:

- Customer Churn Overview
- Customer & Churn Analysis
- Churn Risk & Retention Opportunities

**File:** `Telco_Customer_Churn_Analysis.pbix`

Open the file with Microsoft Power BI Desktop. The report currently contains 7,043 customer records; see the main README for the SQL dataset row-count discrepancy.
