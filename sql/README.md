# SQL Analysis

This folder contains the SQL scripts used for the Telco Customer Churn Analysis project.

The analysis covers:

1. Data validation
2. Executive churn KPIs
3. Customer profile analysis
4. Contract and tenure analysis
5. Service analysis
6. Billing and payment analysis
7. Customer value analysis
8. Churn segment analysis

**Database:** MySQL 8.0  
**Table:** `orders`

Run the scripts in a MySQL environment after importing the dataset and verifying the table and column names.
